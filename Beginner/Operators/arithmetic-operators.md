Q) What are arithmetic operators?

Ans)
    Arithmetic operators are used to perform mathematical calculations on numbers.
    They help in addition, subtraction, multiplication, division, and other numeric operations.

            💻 Code Examples
                    🔹 List of Arithmetic Operators
                            let a = 10;
                            let b = 3;

                            console.log(a + b); // Addition → 13
                            console.log(a - b); // Subtraction → 7
                            console.log(a * b); // Multiplication → 30
                            console.log(a / b); // Division → 3.333...
                            console.log(a % b); // Modulus (remainder) → 1
                    🔹 Increment and Decrement Operators
                            let x = 5;

                            x++;
                            console.log(x); // 6

                            x--;
                            console.log(x); // 5
                    🔹 Exponentiation Operator (**)
                            let base = 2;
                            let power = 3;

                            console.log(base ** power); // 8

        + adds values
        - subtracts values
        * multiplies values
        / divides values
        % gives remainder
        ++ increments by 1
        -- decrements by 1
        ** raises powerr
